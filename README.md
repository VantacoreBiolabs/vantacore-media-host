# Vantacore Media Host

Public media repository for Vantacore Biolabs social graphics.

## Publishing workflow

**Create graphic → store it in `media/` → use its direct image URL → publish through Windsor.ai → Instagram**

PNG and JPEG files placed in `media/` have stable public URLs.

## Direct image URL

```
https://raw.githubusercontent.com/VantacoreBiolabs/vantacore-media-host/main/media/FILENAME.jpg
```

Only finished, public-ready Vantacore Biolabs media should be stored here.
