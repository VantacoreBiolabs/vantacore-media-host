RANDOM ERROR vs SYSTEMATIC ERROR 🎯

Both can distort a measurement—but they behave differently.

RANDOM ERROR changes unpredictably from one measurement to the next. It makes repeated results spread out. Taking more measurements can reduce its effect on an average, but it does not make every reading perfect.

SYSTEMATIC ERROR pushes results consistently in one direction. A calibration problem or biased method can produce results that look tightly grouped while still missing the true value. Repeating the same biased process will not fix it.

The key lesson: precision means results agree with one another; accuracy means they are close to the true value. A method can be precise without being accurate.
