VALIDATED METHOD ≠ FLAWLESS METHOD 🔬

“Validated” does not mean a test can never be wrong. It means evidence has been collected to show that an analytical procedure is fit for a defined purpose.

Four quick facts:

• Accuracy asks how close results are to an accepted reference value.
• Precision asks how closely repeated measurements agree.
• Selectivity asks whether the procedure can measure the intended analyte despite other components in the sample.
• Working range defines the interval where performance has been demonstrated.

Evidence check: validation belongs to a specific context—including the analyte, sample type, range and operating conditions. A procedure validated for one use is not automatically valid for every matrix, concentration range or laboratory situation. Significant changes may require additional evaluation.
